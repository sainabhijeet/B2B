# Sarab theme attribution

The original Sarab fast-food and restaurant HTML template was designed and
developed by Bestwpware and distributed by ThemeWagon under the MIT licence.

- Source: https://themewagon.com/themes/sarab/
- Demo: https://themewagon.github.io/sarab/

This platform package adapts the visual direction and selected image assets to
the SaaS platform's registry-driven theme contract. Original jQuery and
Bootstrap executables are intentionally not included.
