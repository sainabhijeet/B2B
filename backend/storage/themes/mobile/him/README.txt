HS FITNESS WEB THEME

1. Upload hs-fitness-theme.zip from Super Admin > Themes > Upload.
2. Select platform/channel WEB and use slug hs-fitness.
3. In Distributor Panel open Website Builder > Storefront theme and Apply.
4. Run storefront-web on port 5175.
5. Open http://YOUR-TENANT-SLUG.localhost:5175

The theme package contains JSON, CSS and SVG assets only. UI components are
resolved from the storefront section registry.
