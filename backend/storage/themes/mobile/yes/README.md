# Localization Mobile App Theme

Mobile-first conversion of the supplied `localization-e2e-test` ecommerce theme.

## Included
- Mobile-first visual system
- Sticky mobile header + search
- Swipeable hero
- Horizontal category scroller
- 2-column product grid
- Mobile product detail flow
- Cart and checkout sticky action bars
- 5-tab bottom navigation
- Account/search/wishlist mobile templates
- RTL support
- All original locale JSON files (11 languages)

## Theme colors
- Primary: #2563EB
- Accent: #14B8A6
- Background: #F7FBFF → #FFFFFF
- Text: #172033

## Important
This is a theme package, not a compiled Android/iOS application. Your mobile app/theme engine can map the component definitions to native Flutter, React Native, or its own renderer.
