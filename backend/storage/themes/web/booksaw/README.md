# Luxury Commerce Theme

Production-ready Vue 3 + Vite + Bootstrap 5 ecommerce storefront theme.

## Upload Package

The uploadable file is `theme.zip`. Its archive root contains `theme.json`, `package.json`, `index.html`, `vite.config.js`, `public/`, `src/`, `screenshots/`, and `manifest/`.

## Local Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Theme Features

Home, shop, category, product detail, cart, checkout, wishlist, compare, account, login, register, order history, 404, mega menu, hero slider, quick view, search, dark mode, RTL, sticky header, mobile bottom bar, SEO metadata, accessible controls, responsive grids, and optimized lazy-loaded visual assets.
