# Aurora Commerce installation guide

1. Upload `aurora-commerce-v1.0.0.zip` through Super Admin Theme Manager.
2. Confirm the SHA-256 value supplied beside the archive.
3. Let the validation pipeline inspect the manifest, JSON, assets, previews, and locale parity.
4. Create a draft release and open the desktop, tablet, mobile, RTL, and dark-mode previews.
5. Configure theme settings and edit sections/blocks in Theme Builder.
6. Run translation coverage and accessibility checks.
7. Submit the draft for review, approval, and publication according to the normal lifecycle.

No application code changes are required. The filesystem package remains compatible with the current theme upload and runtime contracts.
