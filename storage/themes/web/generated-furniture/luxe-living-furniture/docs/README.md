# Enterprise Reference Theme

Official neutral B2B starter theme for distributors, procurement teams, and trade catalogues.

All editable copy in templates is a translation key. Locale dictionaries are flat and preserve the loader contract. The package contains responsive token definitions, RTL/dark-mode metadata, preview assets, and upload metadata.

Supported page contracts: home, category, product, cart, checkout, wishlist, search, account, login, register, orders, FAQ, blog, contact, and about.
