Classic B2B Wholesale — sample WEB theme (v1)
==============================================

Storefront key: classic-b2b

Includes:
- templates: home, category, product
- tokens: colors, typography, spacing, layout
- assets/css/theme.css + SVG placeholders (no PNG binaries)

Try locally:
1) Zip this folder (or use ../classic-b2b-theme-v1.zip from repo root storage/themes/web/).
2) Admin → Themes → upload ZIP (validates manifest + templates).
3) Distributor panel → assign theme combo so tenant storefrontKey = classic-b2b.
4) Storefront: tenant host + NEXT_PUBLIC_SITE_URL; routes /cart /checkout /orders /login are app pages (not in JSON).

Prebuilt ZIP (when generated from monorepo):
  saas-platform/storage/themes/web/classic-b2b-theme-v1.zip
