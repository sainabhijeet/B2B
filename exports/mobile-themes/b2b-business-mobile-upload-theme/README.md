# B2B Business Mobile Upload Theme

This ZIP is compatible with the platform theme uploader. It contains `theme.json` at the package root plus templates, tokens, locales, and assets.

Use this ZIP for Admin > Themes > Upload:

`b2b-business-mobile-upload-theme.zip`

The separate Flutter source demo package remains available as `b2b-business-mobile-theme.zip`, but the uploader expects this manifest package format.
