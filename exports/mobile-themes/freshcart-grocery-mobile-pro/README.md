# FreshCart Grocery Mobile Pro

Project-compatible mobile theme package for the SaaS platform theme uploader.

## Structure
- theme.json: manifest and mobile configuration
- templates/: home, category, product templates
- tokens/: colors, typography, spacing, layout
- assets/images/: local banners, categories, products, logo and profile visuals
- locales/: multilingual UI/theme copy

## Usage
Upload this ZIP from the platform theme upload screen, select it as a mobile theme, select a language, then rebuild the app.

## Notes
This ZIP follows the platform theme package format. It intentionally does not include executable Flutter/React source because the project validator rejects source files in theme ZIP uploads.
